# My Favourite Place 🌍

A simple travel website created using HTML and CSS to explore some of my favourite places in India.

## 🌴 Places

- Ooty
- Kodaikanal
- Goa
- Kerala

## 🌐 Live Website

[https://gopika372.github.io/My-Favourite-Place/](https://gopika372.github.io/My-Favourite-Place/)

## 🛠️ Technologies Used

- HTML5
- CSS3

## ✨ Features

- Simple and clean travel website
- Peacock-blue theme
- Moving destination cards
- Separate pages for each place
- Travel images
- Easy navigation between pages
- Responsive design
